# North Sequoia

Static website for northsequoia.com: bookkeeping, consulting, and small business scaling strategy.

Everything lives in `index.html` (inline CSS and JS, fonts from Google Fonts), so it can be hosted on any static host such as GitHub Pages, Netlify, or Cloudflare Pages.
