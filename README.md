# North Sequoia

Static website for northsequoia.com: bookkeeping, consulting, and small business scaling strategy.

Everything lives in `index.html` (inline CSS and JS, fonts from Google Fonts) plus images in `assets/`, so it can be hosted on any static host such as GitHub Pages, Netlify, or Cloudflare Pages.

Notes:
- The contact form opens the visitor's email app with a prefilled message to NorthSequoia@outlook.com. A form service (e.g. Formspree) could replace this later.

Logo files are in `assets/` (`logo-original.png` is the source; the others are transparent versions for light and dark backgrounds).
